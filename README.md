# Timer Game ⏱️

A simple and interactive **Timer Challenge Game** built using **React**.  
The goal of the game is to stop the timer as close as possible to the target time and test your timing accuracy.

---

## 🚀 Features

- Start and stop timer challenge
- Displays remaining time and result (win / lose)
- Modal popup to show the result
- Score calculation based on timing accuracy
- Clean and responsive UI

---

## 🛠️ Tech Stack

- **React**
- **JavaScript (ES6+)**
- **HTML5**
- **CSS / Tailwind CSS**
- **Vite** (for fast development)

---

## 📸 How It Works

1. Click **Start Challenge**
2. Try to stop the timer as close as possible to the target time
3. A result modal appears showing:
   - Remaining time
   - Win / Lose status
   - Score
4. Reset and try again 🎯
